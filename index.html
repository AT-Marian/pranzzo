QUESTIONS & ANSWERS

Frequently Asked Questions

Learn more about how Pranzzo works for your hospitality business.

Do customers need to install an app?

No. Guests simply scan the QR code and access the menu through their phone's browser.

Can Pranzzo be used in hotel rooms?

Yes. Hotels can place a QR code inside each room so guests can order food and beverages directly.

Where does the order go?

Orders can be connected to the hotel's or restaurant's kitchen and POS workflow.

Can restaurants use Pranzzo at tables?

Yes. Each table can have a QR code allowing customers to order directly from their phone.
